Notes

  1. 1
    Command menu (⌘K) — fuzzy filter over Navigate (11 routes) / Cases (live feed) / Actions (4 simulate scenarios). ⌘K opens from anywhere; also opened from the topbar search chip.
  2. 2
    Pending drawer — the WooCommerce mini-cart pattern: always-visible count pill on the “Review decisions” button, slide-out drawer with quick approve/decline and a single “open the case” CTA. Count stays in sync via the noctra:pending-changed event bus.
  3. 3
    Honest empty states are a system rule: “Nothing needs you right now.” — never “NO DATA”.
  4. 4
    Accessibility — skip-to-content link, aria-current on the active nav item, Escape closes overlays, focus-visible ring everywhere, reduced-motion respected.
  5. 5
    Mobile — sidebar becomes an overlay drawer (backdrop + Close ×); route changes close it. See the Mobile wireframe.
