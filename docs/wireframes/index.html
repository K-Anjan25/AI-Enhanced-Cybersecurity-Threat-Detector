Legend — wireframe conventions

n
Numbered callout — explained in the Notes list under each board.
X-box — dynamic region (chart, graph, report body, avatar). Never fake data.
night
Night canvas — the analyst’s voice (AI briefs, evidence, blast radius, reports). Dark in both themes.
Primary
Violet appears only where the brand puts it: mark, active nav, primary actions.
HIGH
Severity = dot + label — never color alone.
mono
JetBrains Mono — identifiers, numbers, timestamps, machine values.

System rules these wireframes encode

DUALITY
Day workspace for working surfaces; night canvas wherever the analyst speaks (briefs, evidence, blast radius, reports). Night stays dark in both themes.
Loop-first IA
MAIN nav = Sense → Reason → Decide → Report (Home / Cases / Actions / Reports). Everything else is progressive disclosure in Investigate / Automate / System — never removed.
Honesty
No fabricated metrics, no “NO DATA”. Empty states are hand-written sentences. Missing artifacts say “skipped”.
Calm alarm
Color is alarm — only “waiting on you” warms up. Severity is always dot + label. Record-only vocabulary (“recorded”, never “executed”).
Type
Sora for brand moments (page titles, case headlines); Inter for UI; JetBrains Mono for identifiers/numbers/timestamps. Fluid clamp() scale.
Components
Pages compose the shared kit: PageHeader, Card, StatCard, Badge/SeverityBadge/StatusBadge, EmptyState, Modal, ConfirmDialog, Select, Term.
