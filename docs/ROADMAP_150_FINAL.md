## Final10 OS (P91-P100) — What Are These APIs For?

### P91 Federated Intel Sharing `/federated-intel`
**Purpose:** Share threat intel across organizations without leaking PII. Federated learning for intel.
- `GET /federated-intel/` — list IntelSharePackage (STIX bundles shared)
- `POST /federated-intel/` — create package `{name, stix_bundle, tlp=AMBER, is_anonymized=true, recipient_orgs}` — anonymizes, encrypts, shares via federated mesh
- Models: IntelSharePackage, IntelShareConsent (who consented to share)
- Use: When you detect APT, auto-share IOCs to trusted orgs. GDPR-safe, TLP-controlled.

### P92 Quantum-Safe `/quantum-safe`
**Purpose:** Prepare for Q-Day (quantum breaks RSA/ECC). Inventory crypto, plan migration to PQC.
- `GET /quantum-safe/inventory` — scans codebase/cloud for crypto usage (RSA 2048, ECC P-256, etc) — returns CryptoInventory
- `POST /quantum-safe/scan` — force rescan
- `POST /quantum-safe/migration-plan` — `{name, inventory_ids, target_algorithm=Kyber-768}` — creates QuantumMigrationPlan with timeline, risk, cost
- Models: CryptoInventory (algorithm, location, risk), QuantumMigrationPlan
- Use: CISO dashboard: "30% of your TLS is quantum-vulnerable, migrate to Kyber-768 by 2027"

### P93 Attack Path `/attack-path`
**Purpose:** Graph-based attack path analysis — how attacker moves from entry to crown jewels.
- `GET /attack-path/` — list analyzed paths (if none, auto-analyzes)
- `POST /attack-path/analyze` — runs graph analysis on assets, vulnerabilities, identities — finds shortest path to domain admin, etc.
- Models: AttackPath (nodes, edges, risk_score, blast_radius), AttackPathFinding (chokepoint)
- Use: "Attacker on workstation X can reach DC in 3 hops via T1078 valid accounts -> T1053 scheduled task -> T1021 RDP. Patch here."

### P94 CART — Continuous Automated Red Teaming `/cart`
**Purpose:** Always-on automated red team — emulates adversary continuously, not yearly pentest.
- `GET /cart/jobs` — list CART jobs (scheduled adversary emulations)
- `POST /cart/jobs` — `{name, description, schedule_cron="0 2 * * *", config}` — create job
- `POST /cart/jobs/{job_id}/run` — execute now — creates CART_Execution, then CART_Finding
- Models: CART_Job (cron, MITRE techniques), CART_Execution (logs), CART_Finding (detection gap)
- Use: Every night at 2am, emulate APT29: T1078 valid accounts, T1053, T1021, T1041 exfil — did we detect? Auto-creates finding if not.

### P95 Data Fabric `/data-fabric`
**Purpose:** Unified query layer over all data sources (SIEM, lake, SaaS, cloud) — like Presto/Trino for SOC.
- `GET /data-fabric/sources` — seeds + lists sources (Snowflake, S3, CrowdStrike, Okta, etc) — DataFabricSource
- `POST /data-fabric/query` — `{query="SELECT * WHERE ip=1.2.3.4", sources=[1,2]}` — federated query across sources, returns DataFabricQuery + DataFabricView
- Models: DataFabricSource (type, connection), DataFabricQuery (SQL), DataFabricView (materialized)
- Use: Analyst: "Show me all logs for user X across Okta, CrowdStrike, VPC flow in one query" — fabric does it.
